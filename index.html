Digit Recognition Using CNN

This deep learning system features an interactive Tkinter GUI canvas where users can draw any digit (0-9) with their mouse. The underlying Convolutional Neural Network (CNN) processes the pixel matrix in real time, normalizes the grayscale values, feeds it through MaxPool2D and Dense layers, and outputs the confidence score with >98.7% accuracy.

Python TensorFlow/Keras CNN OpenCV Tkinter
