# Shradhansh Tiwari - Personal Developer Portfolio 🚀

A high-performance, modern, and responsive personal portfolio website for **Shradhansh Tiwari**, built with HTML5, Vanilla CSS3, JavaScript, and GSAP animations.

## 🌟 Key Features

- **Red & Black High-End Aesthetic**: Glassmorphism cards, glowing ambient accents (`#E53935`), dark mode default (`#0D0D0D`).
- **Interactive Hero Section**:
  - Live canvas particle network reacting to mouse movement.
  - Subtitle typing effect (`Full Stack Developer`, `Problem Solver`, `UI Enthusiast`, `AI/ML Developer`).
  - Direct resume download & contact action buttons.
- **About Me**:
  - Circle aspect-ratio profile avatar framing.
  - Quick personal info cards & animated statistic counters.
- **Skills & Toolkit**:
  - Category filter tabs (`All`, `Frontend`, `Backend`, `Database`, `Languages`, `Tools`).
  - 3D card tilt physics, glow states, and progress bar filling.
- **Highlighted Projects & Modals**:
  - **Digit Recognition Using CNN** (Python, TensorFlow, OpenCV, Tkinter).
  - **ShowcaseX 🚀 Portfolio Builder** (Node.js, Express, MongoDB, React, JWT).
  - Interactive preview modal dialogs with direct repository links.
- **Achievements & Metrics**:
  - 100+ DSA Problems Solved.
  - 2+ Deployed Apps.
  - 5+ Certifications & Projects.
- **Contact Form**:
  - Real-time client-side email format validation.
  - Animated button ripple effects and instant feedback state.

## 🚀 How to Run Locally

### Option 1: Python Built-in HTTP Server (Recommended)
```bash
python3 -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### Option 2: Node.js & npm
```bash
npm start
```
